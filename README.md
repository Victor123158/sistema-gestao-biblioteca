# Sistema de Gestão de Biblioteca

Sistema Web empresarial para gestão de uma biblioteca, desenvolvido para fins académicos.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Git/GitHub

## Funcionalidades
- Autenticação de utilizadores
- Dashboard
- CRUD de livros
- CRUD de autores
- CRUD de categorias
- CRUD de utilizadores
- Registo de empréstimos e devoluções
- Pesquisa
- Validação de formulários
- Controlo de erros
- Interface responsiva

## Como executar
1. Coloque a pasta no `htdocs` do XAMPP.
2. Inicie Apache e MySQL.
3. Crie a base de dados importando `database/biblioteca.sql` no phpMyAdmin.
4. Confirme os dados de conexão em `config/database.php`.
5. Acesse `http://localhost/sistema-gestao-biblioteca/`.
